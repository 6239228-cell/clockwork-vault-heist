The Clockwork Vault 齿轮金库 — a top-down heist game: break into the bank vault, dodge the guards' vision cones and the rotating security cameras, slip past the laser grids, grab the gold bar and the gems, and get back to the getaway van before the timer runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve game/ with any static server.
